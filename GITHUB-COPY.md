# VECTOR CRM — копия исходного кода

Этот репозиторий содержит код рабочей CRM на Sites, включая вход по почте и паролю, роли и управление доступами.

## Работающая система

https://vector-crm-pavel.divine-lime-4457.chatgpt.site

Копирование кода в GitHub не переносит рабочую базу данных и не меняет адрес сайта.

## Запуск и сборка

Node.js 22.13+; npm ci; npm run build. Сборка: dist/client (интерфейс), dist/server/index.js (Cloudflare Worker). D1 — binding DB. Для размещения вне Sites необходимо подключить собственную базу D1 и статические файлы к ASSETS.

## Доступ

Владелец на текущем сайте открывает «Доступы», задаёт свою почту и пароль и создаёт сотрудников с ролями «Просмотр» / «Редактор». Общей регистрации нет. Пароли хранятся как PBKDF2-хеш с индивидуальной солью; сессии — HttpOnly Secure cookies. API-ключи задаются только в секретах хостинга.

ВАЖНО ДЛЯ ДРУГОГО ХОСТИНГА: доверенные заголовки oai-authenticated-user-* в src/access.js предназначены только для защищённого шлюза Sites. При переносе на другой хостинг отключите этот путь аутентификации и настройте владельца отдельно; никогда не доверяйте таким заголовкам от посетителей. Этот репозиторий не выполняет автоматическое внешнее развёртывание.

## Что не входит

В репозитории нет рабочей базы, паспортов, загруженных фото/видео, договоров, паролей и API-ключей. Файлы в public — ресурсы приложения; данные в src/seed.js — демонстрационные. Для переноса данных требуется отдельная полная резервная копия D1 (включая file_chunks). Экспорт карточек JSON не содержит исходных вложений.
